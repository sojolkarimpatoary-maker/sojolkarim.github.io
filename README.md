# Sojol Karim — Cybersecurity Portfolio

A responsive, framework-free personal portfolio for Sojol Karim.

## Included

- Responsive design for laptop, MacBook, iPad, iPhone, and mobile screens
- White / minimal visual theme
- Sticky responsive navigation bar
- CSS 3D rotating cube
- About, Skills, Education, Projects, and Contact sections
- Email contact button
- No build step and no external dependencies
- GitHub Pages compatible

## GitHub Pages deployment

1. Create a GitHub repository (for example: `sojol-karim-portfolio`).
2. Upload `index.html`, `styles.css`, and `script.js`.
3. In GitHub, open **Settings → Pages**.
4. Choose **Deploy from a branch**, select the main branch, and choose `/ (root)`.
5. Save. GitHub will provide the live Pages URL.

## Customize later

Replace the sample learning-project text with your real projects, CTF write-ups, certifications, GitHub profile, and social links as you build them.
